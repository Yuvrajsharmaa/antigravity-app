# Support

## Where to Ask

- Use GitHub Issues for bugs and feature requests.
- Use GitHub Discussions (if enabled) for general product or roadmap questions.

## Maintainer Contact

If you need direct maintainer contact (including security matters), open an issue and label it `maintainer-contact` with minimal sensitive detail. A private follow-up channel will be provided.

## What to Include in Any Support Request

- platform and OS
- app/runtime version
- exact reproduction steps
- expected behavior
- actual behavior
- logs, screenshots, or short video if relevant
