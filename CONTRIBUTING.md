# Contributing to CareSpace

Thanks for your interest in improving CareSpace.

## Before You Start

- Read [README.md](README.md) for project context.
- Check open issues for duplicates.
- For major work, open an issue first and describe your approach.

## Development Setup

```bash
npm install
npm run start
```

## Contribution Workflow

1. Fork the repository.
2. Create a branch: `feat/<short-topic>` or `fix/<short-topic>`.
3. Keep PRs focused and small.
4. Add context in your PR description:
   - what changed
   - why it changed
   - screenshots or screen recordings for UI updates
5. Link related issues.

## Pull Request Checklist

- Project starts locally.
- No unrelated refactors mixed into your PR.
- Documentation is updated if behavior changed.
- UI changes include visual evidence.

## Communication Standards

- Be direct, respectful, and specific.
- Assume good intent.
- Prefer reproducible examples over opinions.

## Scope Guardrail

If you are unsure whether a change fits the roadmap, open a discussion in an issue before implementation.
