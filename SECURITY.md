# Security Policy

## Supported Scope

Security reports should focus on vulnerabilities that could impact:
- authentication and account access
- user data confidentiality
- session handling and permissions
- backend data rules and API misuse

## Reporting a Vulnerability

Please do not open public GitHub issues for security findings.

Instead, contact maintainers privately with:
- affected component or file path
- clear reproduction steps
- potential impact
- suggested mitigation (if available)

See [SUPPORT.md](SUPPORT.md) for the contact route.

## Disclosure Process

- We acknowledge valid reports as quickly as possible.
- We investigate and define impact.
- We patch and validate.
- We coordinate disclosure timing with the reporter.

## Safe Harbor

We support good-faith security research and request that testing avoids user harm, data exfiltration, service disruption, or privacy violations.
