# GitHub Profile Upgrade Checklist (No App Code Changes)

Use this checklist across your account repositories to improve OSS credibility fast.

## Tier 1 (same day)

- Add strong README to each public repo.
- Add CONTRIBUTING, SECURITY, SUPPORT, and CODE_OF_CONDUCT files.
- Add issue forms and PR template.
- Pin your best 6 repositories on your GitHub profile.
- Update profile bio with your maintainer focus and stack.

## Tier 2 (this week)

- Add at least 10 labels (`bug`, `enhancement`, `good first issue`, `help wanted`, etc.).
- Convert backlog into public issues with clear acceptance criteria.
- Mark 3 to 5 issues as `good first issue`.
- Add project roadmap milestones.
- Enable Discussions for community Q&A.

## Tier 3 (ongoing)

- Weekly changelog updates in releases or discussions.
- Close stale issues with a respectful resolution note.
- Review PRs with reproducible test notes.
- Keep docs and setup instructions synchronized with product changes.

## Anti-Pattern Avoidance

Do not try to inflate metrics artificially. Focus on maintainership quality signals and authentic contributor operations.
