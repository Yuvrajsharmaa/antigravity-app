# CareSpace

CareSpace is an open-source mental health support app focused on practical therapy workflows for both clients and therapists.

The project provides:
- dual-role product flows (client and therapist modes)
- therapist discovery and session booking
- in-app chat and care-plan nudges
- daily mental health check-ins and trend tracking
- Supabase-backed realtime collaboration patterns

## Why This Project Exists

Mental healthcare apps often optimize for either tracking or therapy operations, but not both. CareSpace is built to close that gap with a single system that supports daily client habits and therapist decision-making together.
